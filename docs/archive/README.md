# Archive

This folder preserves material that is useful for history or implementation context but is not the current architecture contract.

- [Milestones](milestones/): v1 specifications and incremental runtime snapshots. Their implementation limits and deferred-work lists describe the milestone date only.
- [Audits](audits/): completed code audits and hard-cut reports.

Use [Architecture](../architecture/README.md) for current domain ownership and [Migration status](../migrations/README.md) for the status documented by the current tree. Archived records are retained for their evidence and history; they should not be treated as competing current specifications.
